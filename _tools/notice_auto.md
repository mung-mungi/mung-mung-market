# 속보 배너 자동 공개 절차 (정책 타임라인 예약 작업이 끝에 수행, 사용자 2026-11-02 승인 · 2026-11-04 '검수 없이 바로 공개'로 바꿈)

목적: 주인장이 바빠 속보를 못 챙길 때도 '알릴 만한 일'을 놓치지 않게, 타임라인 갱신과 같은 실행에서 배너를 만든다.
**7점 이상·무조건 = 허락 없이 바로 메인 배너로 공개 + 지인 전체 알림**(사용자 2026-11-04). 같은 글은 주인장 칸에도 '자동 공개'로 남는다.
같은 사건(같은 id)을 다시 고치면 배너 내용만 바뀌고 알림은 다시 울리지 않는다. 쓸데없이 자주 울리지 않는 것이 가장 중요하므로 7점 기준을 느슨하게 주지 않는다.

1. 대상: 이번 실행에서 **새로 넣거나 결과로 고친 행 중 tier 'big'** 만. 없으면 아무것도 하지 않는다(판정 기록도 남기지 않음).
2. 같은 사건 중복 금지: `d/notice_inbox.json`(암호문이라 내용은 못 봄) 대신, 이번 실행의 행 id를 판정 id로 쓴다 → `id = 'auto-<행 id>'`. 같은 행을 다시 고친 경우 같은 id라 주인장 칸에서 한 건으로 합쳐진다.
3. 점수(각 0~2, 합 10) — `_tools/notice_kit.py`의 RUBRIC:
   - time 시간 압박: 48시간 안 날짜=2 · 1주 안=1 · 없음=0
   - turn 판이 바뀌나: 흐름 뒤집힘=2 · 세짐=1 · 반복=0
   - ai AI 밸류체인 연결: 직접=2 · 유가·금리 거쳐=1 · 무관=0
   - mkt 시장 충격: 지수·유가·금리 크게=2 · 일부 업종=1 · 없음=0
   - conf 확인도: 1차·복수 매체=2 · 한 곳=1 · 미확인=0
   - force(무조건): 시장 경고등 단계 상승 / 반도체 −5%·나스닥 −3%·유가 ±8% 이상 / 무력 충돌 개시·재개·해협 봉쇄 / 반도체·AI 수출통제 신규·큰 변경 — 해당하면 사유 한 줄
   - why: 항목마다 점수 이유 한 줄(주인장 칸에 보임)
4. 판정 JSON(작업 폴더 W에 저장):
   - 7점 이상 또는 force → **초안**: 11.1 양식 필드 전부(`_tools/notice_kit_sample.json` 모양 그대로) — id·date·title(지금 상황 + 이 글의 역할) / cause[원인 2줄] / k / hint / items[기관·인물 — 핵심 한 줄, body 근거, links 출처] / our(우리 해석 한 줄) / warn(반대 한 줄) / pills[시험대] / src / score / note
   - 5~6점 → **후보**: id·title·date·score·note만
   - 4점 이하 → **기록만**: id·title·score·note만
5. 실행: `python3 -I _tools/notice_kit.py auto W/판정.json /home/claude/mung-mung-market` (비번 필요 없음 — 공개키로 잠금). 결과 파일을 타임라인 커밋에 함께 넣는다: `git add d/notice_inbox.json d/notice_draft.json d/notice.html d/notice_push.json` (없는 파일은 무시). d/notice_push.json이 바뀌면 GitHub의 push-notice가 전체 알림을 보낸다.
6. 끝 줄에 '속보 판정: 제목 n/10 → 자동 공개|후보|기록만' 한 줄을 붙인다.

금지: 비번 사용·요구, notice_kit.py를 거치지 않은 d/notice.html 손수정, push-notice 직접 실행(파일로만), 출처 없는 숫자. 주인장이 손으로 올린 배너가 24시간 안이면 덮어써도 되지만, 끝 줄에 '주인장 배너를 바꿈'이라고 적는다.
